# RozKhata - Native Flutter App Source

While the live preview here runs the web version (React/Vite) of your application configured via Dexie and the same UI/UX specs, here is the structure for your Flutter app as requested. 

To create the real Android App locally on your machine or GitHub Codespaces:

1. \`flutter create rozkhata --org com.rozkhata\`
2. Replace \`lib/\` with standard folder structure:
   - \`lib/screens/\`
   - \`lib/services/\`
   -  ... etc
3. Place your \`google-services.json\` info in \`android/app/\`!
